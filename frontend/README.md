# Koudai Frontend 🥷

This is the Next.js frontend for the Koudai Cyber-Shinobi DeFi Agent.

## 🚀 Getting Started

1. **Install dependencies:**
```bash
npm install
```

2. **Run the development server:**
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the agent in action.

## 🛠 Tech Stack
* **Framework:** Next.js 15 (App Router)
* **Styling:** Tailwind CSS v4
* **State Management:** Zustand
* **Animations:** Framer Motion
* **Data Visualization:** Recharts
* **Icons:** Lucide React

Please refer to the main repository `README.md` in the root folder for full architectural details, backend integration, and hackathon judging criteria.
